### Instant WhatsApp Chat Launcher

WhatsPhone is a lightweight, privacy-friendly web app that lets you start a WhatsApp conversation with any international phone number immediately, avoiding contact list clutter.

- **Direct WhatsApp API:** Uses official WhatsApp deep linking (`wa.me`).
- **Country Code Selector:** Automatic international prefixing and input formatting.
- **Client-Side & Private:** No numbers are logged, sent to external servers, or tracked.
